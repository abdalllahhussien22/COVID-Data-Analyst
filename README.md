# COVID-Data-Analyst 🦠📊

## Project Overview
**COVID-Data-Analyst** is a data analysis project focused on exploring and visualizing global COVID-19 data.  
The project uses real-world datasets to analyze trends in cases, deaths, and vaccinations and presents insights through SQL queries and data visualization tools such as Tableau.

This project is suitable for:
- Data analysts / data science beginners
- Portfolio projects
- Learning SQL and data visualization
- Practicing real-world data exploration

---

## Dataset Description
The project includes the following datasets:

- **CovidDeaths.xlsx**  
  Contains data related to COVID-19 cases, deaths, and population by country and date.

- **CovidVaccinations.xlsx**  
  Contains information about vaccination progress such as number of vaccinated people and doses administered.
